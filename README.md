Soda is a data quality and data observability platform for the modern data stack. Its core abstraction is the data contract — a declarative YAML source of truth that defines the checks a dataset must pass — extended by organization-wide data standards, ML-based metric monitors for anomaly detection, record-level diagnostics, lineage and impact analysis, and AI-assisted contract generation (Contract Autopilot and Copilot). Soda ships an open-source engine (Soda Core), a Go CLI for the whole platform (sodacli), a 103-operation Soda Cloud v4 REST API, a webhook event surface, and a first-party MCP server that exposes 78 tools so agents can manage data quality directly. Soda Data Inc. is headquartered in Belgium.

**Areas:** AIOps · Data Quality · Data Observability · Data Contracts · Data Governance · Anomaly Detection · Data Monitoring · Data Testing

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Soda: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
